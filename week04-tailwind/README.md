# Hill & Hollow Coffee — Week 4 Starter Project

### Decision 1

The commands I tend to use for the container aspect of the code was flex. I gave me better control of what I wanted from the layout, and within that container I used a grid command to it organize better when resizing it for viewing.

### Decision 2

Another command that I enjoyed using was leading:relaxed/loose. It made the page look a lot more neater with the word spacing, and the best part about that command is that I can use it in the div container and it will apply it to the section.

### Decision 3

Using the justify-between command helped keep my work evenly distributed to better layouts once I started to work more into the section.

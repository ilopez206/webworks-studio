# WebWorks Studio — Module 9 Student Starter

## Mission City Makers Market

## Project Summary

Added Apline and Preline to their respective sections on the page for the client.

## Alpine Decision

**User/client need:**  
Featured Makers section needed interactive help for future visitors on the webpage to explore the makers.

**Alpine directives used:**  
Made a drop menu for each maker section to view more information.

**Why Alpine was appropriate:**  
Given that the information was already there, adding the small code helped makes the user to be enticed to press the button to view more information about each maker.

## Preline Decision

**Preline component selected:**  
Accordian

**Problem it solves:**  
This improves the clients content by making this section interactive, this also gives options to customize the fonts, text, and colors of the section.

**How you adapted it:**  
This was adapted by taking the old code and keeping the relevant information. And then adding the accordian tool to give it more interacivity.

## Dependencies

**Alpine.js — how used:** Used by working with smaller interactive sections and doesnt need too much complex coding, it is identified by "x" components withing the code, usually within the "div" sections.

**Preline UI — how used:** Uses tailwind and javascript, this code is accessible by coping components from the offical site and implementing them to your page, you can also customize the code and looks of the content.

**Tailwind CSS — how used:** Tailwind is a simple way to customize the content of your page with layout, text, font, and design options without having to code on the css styles page.

# Cedar & Stone Home Services — Week 5 Starter Project

## Project

**Week 5 — Build with a System: Bootstrap**

## 1. Framework Choice

Using the row framework helps keep certain sections that I want to work on organized. I thought it was pretty neat that you can seperate sections into columns and then work into that space. I would say that it was pretty confusing for me to get the gist of it, though I know with time I'll be better at it.

## 2. Adaptation

Putting each section into a container is a better way to maintain the page and to work with the responsivness when working with different screen sizes.

## 3. Professional Judgment

The navbar is something that I would not make from scratch. I liked how bootstrap already had the code on their site and implementing it was pretty easy. It makes more sense to me to have something work consistently and is simple to use and see.
